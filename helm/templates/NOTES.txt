This is a certificate authority operated by you. Its root is in no operating-system, browser or mail-client trust store: its
certificates verify only where the root ({{ include "acme.externalUrl" . }}/ca/roots.pem) has been imported or trusted by policy.

CA material:
  Issuer certificate and key: Secret "{{ tpl .Values.ca.existingSecret . }}", mounted read-only at /var/lib/acme/ca. It is yours to
  create and rotate; the chart never generates or changes it. Create one from a `yarn ca:init` output directory (the root
  private key stays offline, never in this Secret) with:
    scripts/ca-k8s-secret.sh <ca-dir> {{ tpl .Values.ca.existingSecret . }} -- -n {{ .Release.Namespace }}
  which prints the ca.items to put in your values. The service exits at start without a usable issuers.json: check
    kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "rrst.fullname" . }}-services
{{- if .Values.mail.dkim.existingSecret }}
  DKIM key for the verification e-mail: Secret "{{ tpl .Values.mail.dkim.existingSecret . }}", key "{{ .Values.mail.dkim.key }}".
{{- end }}

Verification e-mail (RFC 8823):
  From:     {{ include "acme.mailFrom" . }}
  Reply-To: {{ include "acme.mailReplyTo" . }}   <- applicants' replies must reach this address
{{- if .Values.mail.dkim.existingSecret }}
  DKIM:     d={{ include "acme.dkimDomain" . }}, selector {{ .Values.mail.dkim.selector }}
{{- end }}
DNS records to publish (details in docs/DEPLOYMENT.md):
  * {{ include "acme.host" . | default "<host>" }}: A/AAAA (or CNAME) to the Gateway's address.
{{- if .Values.mail.dkim.existingSecret }}
  * {{ .Values.mail.dkim.selector }}._domainkey.{{ include "acme.dkimDomain" . }}: TXT "v=DKIM1; k=rsa; p=<the public key>".
{{- end }}
  * {{ regexReplaceAll "^.*@" (include "acme.mailReplyTo" .) "" }}: MX to the host that receives the replies (below).
  * {{ regexReplaceAll "^.*@" (include "acme.mailFrom" .) "" }}: SPF (TXT) authorising the outbound SMTP relay; optionally DMARC.

{{- if .Values.admin.enabled }}

The operator API (search and revoke certificates, suspend accounts) is not routed publicly. Reach it from inside the cluster or:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "rrst.fullname" . }}-services 3000:3000
  ADMIN=$(kubectl -n {{ .Release.Namespace }} get secret {{ .Values.secrets.existingSecret | default (printf "%s-secrets" (include "rrst.fullname" .)) }} -o jsonpath='{.data.acme__admin_secret}' | base64 -d)
  curl -H "Authorization: Bearer $ADMIN" -H "X-Operator: you@example.org" "http://localhost:3000/admin/certificates?email=someone@example.com"
{{- end }}
